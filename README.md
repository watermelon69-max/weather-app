🌦️ Weather App

A simple Weather App that shows real-time weather information for any city using a weather API.
Built to practice HTML, CSS, JavaScript, and API fetching.

🚀 Features

Search weather by city name

Displays:

Temperature

Weather condition (rain, clouds, clear, etc.)

Humidity

Wind speed

Dynamic weather icons based on conditions

Responsive and clean UI

🛠️ Tech Stack

HTML

CSS

JavaScript

OpenWeather API

Netlify (for deployment) 

🔑 API Used

OpenWeather API
